# Character Manager

> **Менеджер Персонажей · МП**

Character Manager (Менеджер Персонажей, далее **МП**) — это веб-приложение по управлению своими персонажами в настольных ролевых играх (**НРИ**).

МП позволяет создавать персонажей, менять их, использовать их за игровыми столами. Это универсальное приложение, избавляющее игрока от пользования множеством сайтов, а также позволяющее портативно носить персонажей с собой на игровые сессии.

МП помогает удобно управлять своим чарником и быстро находить ссылки на оригинальные правила.

---

## 01. Основной сценарий

### Основной жизненный цикл персонажа

#### 01. Выбор игровой системы НРИ

Пользователь выбирает одну из систем НРИ:

- **D&D 5e**
- **Pathfinder 2e**

#### 02. Создание персонажа

Пользователь создаёт своего персонажа с помощью доступных средств в МП.

По итогу пользователь получает готовый лист персонажа, где будет отображаться информация о его герое:

- навыки;
- характеристики;
- инвентарь;
- магия;
- и т. п.

#### 03. Редактирование персонажа

Пользователь может изменять любую информацию в листе персонажа.

Например:

- характеристики;
- инвентарь;
- способности.

#### 04. Поделиться персонажем

Пользователь может создать ссылку на своего персонажа, которую сможет открыть другой пользователь.

#### 05. Сохранение персонажа

Сохранение текущего состояния листа персонажа, в том числе выгруженного от другого игрока.

#### 06. Удаление персонажа

Пользователь может удалить лист персонажа.

## 02. Функциональность

### Список фичей в МП

> **MVP:** фичи **01–05** входят в первую версию продукта.

### 01. Выбор игровой системы НРИ `MVP`

МП поддерживает разные НРИ.

Поскольку НРИ могут сильно отличаться друг от друга по наполнению, выбор системы сильно влияет на доступные в будущем игроку инструменты работы с **ЛП** (далее — лист персонажа).

Системы между собой независимы.

### 02. Создание персонажа `MVP`

Инструмент по созданию персонажа **1-го уровня**.

### 03. Прокачка персонажа `MVP`

Прокачка персонажа до максимального уровня, доступного в системе.

### 04. Динамическое управление `MVP`

Возможность менять уже выбранные:

- фиты;
- характеристики;
- другие элементы, выбранные ранее при прокачке персонажа.

### 05. Инвентарь `MVP`

Пользователь может:

- добавить предмет в свой инвентарь;
- редактировать предмет;
- удалить предмет;
- найти информацию о своих вещах.

МП будет уделять внимание удобству использования инвентаря.

В качестве ориентира — инвентарь из **Foundry VTT**.

Предметы можно будет искать:

1. в отведённых компендиумах;
2. с помощью строки быстрого поиска.

### 06. Статус персонажа

Удобная справочная информация обо всех способностях и статусах на герое.

Не входит в MVP, но в дальнейшем будут добавлены инструменты для наложения **бафов** и **дебафов** на героя, чтобы динамически менять характеристики персонажа.

Здесь же будет находиться магия.

### 07. Файтинг

Броски кубов прямо из чарника.

Использование:

- атак;
- магии;
- навыков

прямо из окна статуса героя.

## MVP

> **MVP включает в себя создание и редактирование персонажа.**  
> По списку фичей должны быть реализованы пункты **с 01 по 05**.
